界面采用前后依赖的步骤化操作，应使用长条形结构来避免来回翻页的麻烦
暂不考虑批量操作
Windows 缓存文件夹：%USERPROFILE%\encoder
Linux 缓存文件夹：$HOME\encoder

1. 主界面
    a. 选择上游程序
        - 选项集合：ffmpeg、vspipe、avs2yuv、avs2pipemod、SVFI（包含 one_line_shot_args.exe 的检测支持）
        - 显示内容：显示所选程序的可执行路径、程序全名、版本信息（如通过执行 --version/获取元数据得到）
        - 设置界面导入并保存程序路径
    b. 选择下游程序
        - 选项集合：x264、x265、SvtAv1EncApp
        - 显示内容：同上，显示路径、程序全名、版本信息
        - 设置界面导入并保存程序路径
        - 显示编码器版本
            - UI 显示区域直接展示版本文本，必要时提供“是否兼容”的简要状态
    c. 选择分析程序、上游程序依赖的文件
        - 选项集合：ffprobe、AviSynth.dll
        - 显示内容：路径输入框、程序全名、版本
        - 设置界面导入并保存
    d. 选择和生成源文件
        - 基于上游程序的源/脚本能力呈现不同的“源类型”可选组合
            - ffmpeg：视频源（默认主要处理对象，不暴露复杂脚本源以避免界面混乱）
            - vspipe、avs2yuv：脚本源 + 视频源
            - avs2pipemod：脚本源 + 视频源；依赖 AviSynth.dll
            - SVFI：视频源 + 脚本源；支持 Config 路径 X:\SteamLibrary\steamapps\common\SVFI\Configs\*.ini
        - 显示内容：视频路径、脚本/源的全名或描述
        - AviSynth 与 VapourSynth 脚本
            - 生成无滤镜脚本（实现见 bbenc 步骤 3 的无滤镜脚本生成功能）
            - 导入 .avs/.vpy 脚本
        - 检查源文件是否存在
    e. 视频源分析报告
        - 从 ffprobe 获取 JSON
        - UI 要素：信息列表/面板、红绿灯色警示图标、复制/导出按钮
        - 基础信息报告：将 ffprobe 的分析结果转换成 JSON 形式展示与导出
        - 阻塞警告
            - 元数据损坏：提示视频缺少平均帧率或基础帧率元数据；若确认为可变帧率统计项之一且信息缺失
            - 不兼容：
                - SVT-AV1 不支持 12bit
                - SVT-AV1 不支持隔行扫描
                - x264 不支持杜比视界
                - x264 不支持特定的 CSP 格式
        - 非阻塞警告（给出修正命令或替代参数的建议）
            - 可变帧率
            - 非方形像素
            - x265 的隔行扫描支持为实验性
            - 真实封装格式与后缀名不一致
            - 伪 DVD 流提示
    f. 配置编码选项
        - 视频导出路径
            - 导出目录文本框 + 浏览按钮
        - 编码器线程管理
            - 选择占用线程数：数字输入框或滑块（适用所有编码器）
            - 选择在特定 CPU 上运行（仅对部分编码器可用，如 x265、SVT-AV1）：CPU 树形选择控件（多选/单选时应被明确
        - 指定基础参数集
            - x264：通用、素材、默认值
            - x265：通用、录像、素材、动漫、穷举法、默认值
            - SVT-AV1：画质优先、压缩优先、速度优先、默认值
        - 自动定制参数
            - ffmpeg 上游：隐藏进度条以只呈现编码器进度
            - 上下游管道参数：vspipe API 版本检测逻辑（自动检测版本并在 UI 提示）
            - 上游程序依赖的文件与动态链接库导入参数：Avs2PipeMod-AviSynth.dll、SVFI-ini
            - 编码器输入参数：`-`、`--input -`、`-i -`
            - 编码器输出参数：输出文件后缀名使用 .mp4、.hevc、.ivf
            - 视频基础信息上下游参数：分辨率、帧率、总帧数、SEICSP（矩阵格式、传输特质、原色、HDR 与杜比视界信息等）
            - x264：rc-lookahead
            - x265：pme、subme、rc-lookahead、pools（pools 应改为自动 + 交互定制）
            - SVT-AV1：crf、dlf2（仅 mod 版可选项）
        - 交互定制参数
            - 视频文件名和保存路径
            - x264：keyint（输入秒数换算帧数）、crf、fgo（仅 mod 版，见 bbenc 脚本 4）
            - x265：keyint（输入秒数换算帧数）、crf（区间设置：17-20 | 21-25 | 26-30 | 0 | 默认 28）
            - SVT-AV1：keyint、crf（28-32 | 33-36 | 37-40 | 1 | 默认 35）、dlf2（仅 mod 版，见 bbenc 脚本 4）
    g. 启动选项
        - 阻塞条件（在设置页关闭）
            - 纯电池供电
            - CPU 当前高占用
            - 可用内存太小
                - 预估内存占用 = 位深系数 * 编码器系数 * (参考帧长度 * 连续 B 帧长度)/2 * (亮度像素数量 + 色度像素数量)
            - 磁盘空间不足
                - 预估磁盘占用 = 源视频大小 * 0.9
            - 复查源视频、脚本是否还存在
            - 同名文件存在（确认继续）
                - 要覆盖的文件超过 50MB：倒计时冷却 5 秒
                - 要覆盖的文件超过 100MB 则强制倒计时 10 秒
                - 要覆盖的文件超过 500MB 则要求输入文件名的一部分，并长按确定按钮
                - 要覆盖的文件超过 1.5GB 则可能是素材，拒绝覆盖
        - 启动选项
            - 打样片段（视频正中间 15 秒、偏移秒数）
                - 创建 y-m-d h-m-s、Test 15s Sample ... 之类的的文件名
            - 开始压制
    h. 非片段压制完成状态
        - 重命名视频文件名，避免误操作导致压制结果被覆盖
        - ffprobe 检查输入文件的时长，帧数是否与源一致
        - 展示实际输出大小、平均码率与源的差异
2. 压制信息窗口页
    a. 只读命令行日志窗口：编码器进度等信息
    b. 复制日志
    c. 保存日志（编码完成前锁定）
    d. 终止压制
3. 设置页
    a. 导入上游程序
    b. 导入下游程序（编码器）
    c. 导入分析程序与 AviSynth.dll
    d. 禁用阻塞条件选项
4. 确认页
    a. 确认信息（覆盖同名文件）
    b. 确认按钮（遇到阻塞状况则锁定）
    c. 取消按钮
