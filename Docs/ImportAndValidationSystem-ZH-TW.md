# 1cenc 導入與檢查系統

本文件用於說明影片的導入和檢查系統

---

## 1. 術語

| 詞 | 說明 |
|---|---|
| 源 | 你導入的影片檔案。程序主要關心畫面流，不是音訊串流。 |
| 多文件模式 | 隊列、拼接、重分集三種模式的統稱。 |
| ffprobe | 讀取影片參數的工具，能讀出解析度、幀率、像素格式、色彩、場序等。 |
| 檢查列表 | 程序對每個源逐項體檢：元數據、逐行、位深、固定幀率、YUV420、色度等。 |
| 錯誤 / 警告 | 錯誤會禁用開始按鈕；警告只提醒，不禁用開始按鈕。 |
| 非白名單拒絕 | 只要有一個文件不符合白名單，整個導入會被拒絕並彈錯。 |
| 參考文件 | 多文件模式中的基準文件，其他文件和它比較。 |
| 固定幀率 / 可變幀率 | 固定幀率通常沒問題；可變幀率很多工具不支持。 |
| 逐行 / 隔行 | 逐行通常沒問題；隔行是古早掃描方式，現代工具通常不支持。 |
| 參數指紋 | 一組影片參數的摘要，用來判斷多個文件是否完全一致。 |
| 音訊復用 | 直接複製音訊或重新編碼。拼接和重分集默認重新編碼為 AAC 320 kbps，避免丟聲或不同步。 |

## 2. 所有模式共通的規則

| 規則 | 說明 | 影響 |
|---|---|---|
| 路線優先度 | 隊列 > 拼接 > 重分集 > 單文件 | 多個模式同時啟用時，按這個順序決定用哪個 |
| 對話框副檔名過濾 | 約 90 項的白名單；腳本支持 .avs、.vpy、.ini | 文件選擇窗只顯示影片副檔名的文件 |
| All files 的影響 | 所有對話框都有 All files | 仍可強行選用任意文件 |
| 檢查列表 | 元數據、逐行、位深、固定幀率、方形象素、顏色、色度、YUV420 等 | 每個源都會體檢；錯誤禁用開始壓制按鈕，警告不禁用 |
| 元數據 | 不能是 unknown、unspecified、reserved | 元數據異常通常說明源可能損壞 |
| 逐行 | 場序為空、progressive、unknown 視為通過 | 失敗通常是警告 |
| 位深 | 支持 8、10；SVT-AV1 最大 10；其他編碼器最大 12 | 超高位深可能不支持 |
| 固定幀率 | 平均幀率非空、非 0，且等於實際幀率 | 隊列會額外檢查 |
| YUV420 | 像素格式包含 420 | 失敗→警告；選 SVT-AV1 時變為錯誤 |
| 方形象素 | 像素不是長方形 | 失敗→警告並建議加修復濾鏡 |
| 色度採樣 | 採樣位置受工具支持 | SVT-AV1 支持較少，失敗警告 |
| 模式卡片啟用 | 缺 ffprobe 時所有影片源卡禁用；選擇某些上游工具時多文件模式卡禁用 | 工具不齊時主動禁用模式 |
| 啟動前檢查 | 隊列/重分集檢查缺失源、重複輸出；所有路線有覆蓋確認；路線支持檢查 | 缺文件、輸出重名、路線不支持會報錯 |
| 腳本與影片校驗 | 單文件/隊列校驗；拼接/重分集跳過 | 拼接腳本自帶片段列表；重分集不要求腳本源 |
| 拖放匯入 | 主介面可直接拖入影片檔案；拖入 1 個進單文件模式，拖入多個進隊列模式 | 與檔案對話框匯入等價；已有影片源時先確認 |

## 3. 四種導入模式的檢查區別

| 模式 | 導入方式 | 最小源數 | 副檔名二次校驗 | 跨文件嚴格度 | 腳本要求 | 音訊默認 |
|---|---|---|---|---|---|---|
| 單影片 | 單文件 | 1 | 無 | 無 | 單腳本源 | — |
| 隊列模式 | 多選、藍光播放列表 | 大於 0 | 有，非白名單報錯 | 中等 | 腳本隊列文件夾 | — |
| 拼接模式 | 多選 | 至少 2 | 有，非白名單報錯 | 較嚴 | 腳本內嵌片段列表 | 重新編碼為 AAC 320 kbps |
| 重分集模式 | 文件導入、章節文件夾 | 大於 0 | 有，非白名單報錯 | 嚴格 | 不要求腳本源 | 重新編碼為 AAC 320 kbps |

## 4. 多文件模式：源能不能一起用

| 檢查項 | 隊列模式 | 拼接模式 | 重分集模式 | 解讀 |
|---|---|---|---|---|
| 參考源 | 典型模式按時長²÷幀數²投票；首流模式取首個成功分析文件 | 首個成功分析文件 | 總位元組最大組；平局看數量 | 排除與基準流不同的項 |
| 解析度 | 寬度參與比較 | 不匹配禁用開始壓制按鈕 | 寬高都硬排除 | 拼接、重分集對解析度敏感 |
| 幀率 | 平均幀率和實際幀率參與比較 | 不匹配警告 | 非固定幀率排除 | 幀率不一致可能卡頓或失敗 |
| 可變幀率 | 要求固定幀率 | 提示加修復濾鏡 | 直接排除 | 隊列較嚴，拼接提醒，重分集硬排除 |
| 隔行 | 檢查列表 | 檢查列表 | 標記隔行，提示保留或排除；取消則中止導入 | 重分集會問你 |
| 編解碼/像素格式 | 通過參數指紋檢查 | 不一致警告 | 不一致硬排除 | 重分集最嚴格 |
| 色彩/色度/位深 | 參與比較 | 影響警告 | 硬排除 | 參數不一致時，越嚴越容易排除 |
| 文件穩定性 | — | — | 檢查檔案大小和修改時間 | 重分集會檢查文件是否變了 |
| 總幀數 | 隊列結果可用 | 累加；缺幀則報錯 | 逐文件獲取，失敗排除 | 拼接需要總長度 |

## 5. 各模式專屬規則

### 5.1 單影片模式

| 項目 | 規則 |
|---|---|
| 導入 | 只選一個影片 |
| 選後副檔名校驗 | 無（通過 All files 選中的文件會被接受） |
| 跨文件相容 | 無 |
| 分析條件 | 工具路徑和源路徑都不為空 |
| 分析失敗 | 產生錯誤，阻止啟動 |
| 特殊上游工具 | 使用某些上游工具時，會覆蓋腳本配置 |
| 時長過濾 | 不適用 |
| 啟動 | 上游請求為空則報錯 |
| 腳本影片校驗 | 有 |

### 5.2 隊列模式

| 項目 | 規則 |
|---|---|
| 導入 | 多文件對話框；支持藍光播放列表 |
| 非白名單副檔名 | 錯誤並中止導入 |
| 空結果 | 未選擇任何文件會警告 |
| 混合文件夾 | 可能報錯 |
| 每文件分析 | 逐文件體檢 |
| 單文件失敗 | 跳過並顯示錯誤 |
| 全部失敗 | 不能繼續 |
| 過濾模式 | 文件數大於 1 時，提示首流或典型流 |
| 接受條件 | 關閉過濾則接受；否則候選必須匹配參考 |
| 實際要求 | 相同檢查列表狀態、相同寬度、相同歸一化平均和實際幀率 |
| 不要求 | 高度不參與比較，但顏色資訊參與 |
| 參考選擇 | 典型模式按時長²÷幀數²投票；首流模式取第一個 |
| 結果保存 | 接受和排除結果寫入隊列文件 |
| 時長過濾 | 僅隊列；默認 30 秒；過濾後為空警告 |
| 隊列文件檢查 | 文件缺失、無條目、無效內容都報錯 |
| 啟動前檢查 | 缺失源、重複輸出 |
| 腳本校驗 | 強制執行腳本與影片匹配 |

### 5.3 拼接模式

| 項目 | 規則 |
|---|---|
| 非白名單副檔名 | 錯誤並中止導入 |
| 最小數量 | 少於 2 個錯誤 |
| 同副檔名 | 所有文件必須同副檔名，忽略大小寫 |
| 可變幀率 | 每文件警告，不阻斷 |
| 解析度不匹配 | 阻斷；導入中止，再分析也報錯 |
| 編碼 / 像素格式不一致 | 警告 |
| 幀率不匹配 | 警告 |
| 無影片串流或缺寬高 | 報錯 |
| 單文件探測失敗 | 可能中斷 |
| 全部失敗 | 不能繼續 |
| 幀計數 | 累加總幀數；任一文件缺幀數則總長度不完整 |
| 參考源 | 第一個成功分析的文件 |
| 再分析 | 少於 2 個文件報錯 |
| 啟動數量 | 開始前再次確認至少 2 個 |
| 腳本校驗 | 跳過 |
| 音訊復用 | 默認重新編碼為 AAC 320 kbps |

### 5.4 重分集模式

#### 預檢與階段排除

| 階段 | 檢查 | 結果 | 說明 |
|---|---|---|---|
| 預檢 | 缺少 ffprobe | 不能繼續 | 做飯沒鍋 |
| 預檢 | 沒有源 | 不能繼續 | 無米之炊 |
| 文件檢查 | 文件不存在 | 排除 | 文件被刪或移動 |
| 輕量分析 | 分析失敗 | 排除 | 文件讀不了 |
| 深入分析 | 分析失敗 | 排除 | 影片參數讀不出來 |
| 流檢查 | 沒有影片串流 | 排除 | 沒有畫面流 |
| 流檢查 | 寬高無效 | 排除 | 尺寸不正常 |
| 流檢查 | 不是固定幀率 | 排除 | 必須是固定幀率 |
| 流檢查 | 隔行 | 提示保留或排除；取消則中止導入 | 隔行會問你，說不定是偽隔行 |
| 參考比較 | 參數指紋不一致 | 排除 | 影片參數必須完全一致 |
| 幀數檢查 | 幀數無效 | 排除 | 無法確定幀數 |
| 幀數檢查 | 文件被改過 | 排除 | 分析後檔案大小或修改時間變了 |
| 幀數檢查 | 幀數估算未驗證 | 提示確認；取消則中止導入 | 不精確時會問你 |

#### 參數指紋說明

| 類別 | 內容 |
|---|---|
| 編碼 | 編碼器、配置、級別 |
| 尺寸 | 寬、高、編碼寬、編碼高 |
| 像素 | 像素格式、位深 |
| 場序 | 逐行還是隔行 |
| 寬高比 | 像素寬高比 |
| 幀率 | 平均幀率、實際幀率 |
| 色彩 | 顏色範圍、顏色空間、傳輸特性、原色、色度位置 |
| 額外數據 | 編碼器額外數據的哈希 |
| 字串處理 | 忽略大小寫和空格 |

#### 幀數獲取順序

按速度排序

| 順序 | 方法 |
|---|---|
| 1 | 使用快取幀數 |
| 2 | 按時長估算，並抽查驗證 |
| 3 | 無損重封裝精確計數 |
| 4 | 完整數幀，較慢 |
| 5 | 最後用二分搜索 |

#### 計劃與編輯檢查

| 項目 | 規則 |
|---|---|
| 計劃為空 | 報錯並關閉 |
| 計劃陳舊 | 文件變了，警告並關閉 |
| 文件是否被改 | 檢查檔案大小和修改時間 |
| 刪除源 | 至少留 1 個源 |
| 刪除輸出 | 至少留 1 個輸出 |
| 應用關閉 | 沒有分析或沒有輸出不能保存 |
| 分割線範圍 | 不能越界 |
| 最小片段 | 1 幀 |
| 啟動 | 路線支持、請求有效、缺失源、重複輸出、覆蓋確認 |
| 腳本源 | 不要求 |
| 腳本影片校驗 | 跳過 |
| 音訊復用 | 默認重新編碼為 AAC 320 kbps |

## 6. 主介面拖放匯入

主介面（MainUI）可以直接接收從檔案總管拖入的影片檔案，匯入規則與檔案對話框等價。
檢視層（MainUI）負責接收 OLE 拖放事件與「可以放開」的視覺回饋，規則層（MainVM）負責匯入決策。

| 項目 | 規則 |
|---|---|
| 接收範圍 | 主介面整體（含視窗捲動區）為拖放目標 |
| 拖入 1 個影片 | 匯入到單文件模式 |
| 拖入多個影片 | 匯入到隊列模式（多檔案模式） |
| 拖入資料夾 | 忽略資料夾；找不到可用檔案時提示沒有影片檔案 |
| 副檔名校驗 | 單文件模式不二次校驗（非白名單檔案也會被接受）；隊列模式按白名單校驗，出現非白名單檔案則報錯並中止匯入 |
| 目標卡片被停用 | 提示無法匯入（缺少 ffprobe，或所選上游不支援隊列模式） |
| 已有影片源 | 彈確認框；確認則替換並繼續匯入，取消則保留原影片源 |
| 懸停回饋 | 拖入懸停時主介面顯示高亮遮罩與提示文字（單文件模式 / 隊列模式），表示可以放開 |
| 匯入之後 | 與檔案對話框匯入一致，自動執行影片源檢查 |
| 不支援的操作 | 只處理影片檔案；腳本源仍需用檔案對話框匯入 |
