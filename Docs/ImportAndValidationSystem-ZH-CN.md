# 1cenc 导入与检查系统

本文档用于说明视频的导入和检查系统

---


## 1. 术语

| 词 | 说明 |
|---|---|
| 源 | 你导入的视频文件。程序主要关心画面流，不是音频流。 |
| 多文件模式 | 队列、拼接、重分集三种模式的统称。 |
| ffprobe | 读取视频参数的工具，能读出分辨率、帧率、像素格式、色彩、场序等。 |
| 检查列表 | 程序对每个源逐项体检：元数据、逐行、位深、固定帧率、YUV420、色度等。 |
| 错误 / 警告 | 错误会禁用开始按钮；警告只提醒，不禁用开始按钮。 |
| 非白名单拒绝 | （已移除）扩展名不再单独决定拒绝；唯一裁决是 ffprobe 读不出数据 |
| ffprobe 唯一裁决 | 文件能否导入/参与，只由 ffprobe 是否读出数据决定；多文件模式读不出→逐文件排除并汇总，单文件→报错 |
| 参考文件 | 多文件模式中的基准文件，其他文件和它比较。 |
| 固定帧率 / 可变帧率 | 固定帧率通常没问题；可变帧率很多工具不支持。 |
| 逐行 / 隔行 | 逐行通常没问题；隔行是古早扫描方式，现代工具通常不支持。 |
| 参数指纹 | 一组视频参数的摘要，用来判断多个文件是否完全一致。 |
| 音频复用 | 直接复制音频或重新编码。拼接和重分集默认重新编码为 AAC 320 kbps，避免丢声或不同步。 |

## 2. 所有模式共通的规则

| 规则 | 说明 | 影响 |
|---|---|---|
| 路线优先级 | 队列 > 拼接 > 重分集 > 单文件 | 多个模式同时激活时，按这个顺序决定用哪个 |
| 对话框扩展名过滤 | 约 90 项的白名单；脚本支持 .avs、.vpy、.ini | 文件选择窗只显示视频扩展名的文件（仅 UI 过滤，不参与拒绝） |
| All files 的影响 | 所有对话框都有 All files | 仍可强行选用任意文件 |
| 检查列表 | 元数据、逐行、位深、固定帧率、方形像素、颜色、色度、YUV420 等 | 每个源都会体检；错误禁用开始压制按钮，警告不禁用 |
| 元数据 | 不能是 unknown、unspecified、reserved | 元数据异常通常说明源可能损坏 |
| 逐行 | 场序为空、progressive、unknown 视为通过 | 失败通常是警告 |
| 位深 | 支持 8、10；SVT-AV1 最大 10；其他编码器最大 12 | 超高位深可能不支持 |
| 固定帧率 | 平均帧率非空、非 0，且等于实际帧率 | 队列会额外检查 |
| YUV420 | 像素格式包含 420 | 失败→警告；选 SVT-AV1 时变为错误 |
| 方形像素 | 像素不是长方形 | 失败→警告并建议加修复滤镜 |
| 色度采样 | 采样位置受工具支持 | SVT-AV1 支持较少，失败警告 |
| 模式卡片启用 | 缺 ffprobe 时所有视频源卡禁用；选择某些上游工具时多文件模式卡禁用 | 工具不齐时主动禁用模式 |
| 启动前检查 | 队列/重分集检查缺失源、重复输出；所有路线有覆盖确认；路线支持检查 | 缺文件、输出重名、路线不支持会报错 |
| 脚本与视频校验 | 单文件/队列校验；拼接/重分集跳过 | 拼接脚本自带片段列表；重分集不要求脚本源 |
| 拖拽导入 | 主界面可直接拖入视频文件；拖入 1 个进单文件模式，拖入多个进队列模式 | 与文件对话框导入等价；已有视频源时先确认 |

## 3. 四种导入模式的检查区别

| 模式 | 导入方式 | 最小源数 | 导入闸门 | 跨文件严格度 | 脚本要求 | 音频默认 |
|---|---|---|---|---|---|---|
| 单视频 | 单文件 | 1 | 无（ffprobe 复检） | 无 | 单脚本源 | — |
| 队列模式 | 多选、蓝光播放列表 | 大于 0 | 无（ffprobe 复检） | 中等 | 脚本队列文件夹 | — |
| 拼接模式 | 多选 | 至少 2 | 无（ffprobe 复检） | 较严 | 脚本内嵌片段列表 | 重新编码为 AAC 320 kbps |
| 重分集模式 | 文件导入、章节文件夹 | 大于 0 | 无（ffprobe 复检） | 严格 | 不要求脚本源 | 重新编码为 AAC 320 kbps |

## 4. 多文件模式：源能不能一起用

| 检查项 | 队列模式 | 拼接模式 | 重分集模式 | 解读 |
|---|---|---|---|---|
| 参考源 | 典型模式按时长²÷帧数²投票；首流模式取首个成功分析文件 | 首个成功分析文件 | 总字节最大组；平局看数量 | 排除与基准流不同的项 |
| 分辨率 | 宽度参与比较 | 不匹配禁用开始压制按钮 | 宽高都硬排除 | 拼接、重分集对分辨率敏感 |
| 帧率 | 平均帧率和实际帧率参与比较 | 不匹配警告 | 非固定帧率排除 | 帧率不一致可能卡顿或失败 |
| 可变帧率 | 要求固定帧率 | 提示加修复滤镜 | 直接排除 | 队列较严，拼接提醒，重分集硬排除 |
| 隔行 | 检查列表 | 检查列表 | 标记隔行，提示保留或排除；取消则中止导入 | 重分集会问你 |
| 编解码/像素格式 | 通过参数指纹检查 | 不一致警告 | 不一致硬排除 | 重分集最严格 |
| 色彩/色度/位深 | 参与比较 | 影响警告 | 硬排除 | 参数不一致时，越严越容易排除 |
| 文件稳定性 | — | — | 检查文件大小和修改时间 | 重分集会检查文件是否变了 |
| 总帧数 | 队列结果可用 | 累加；缺帧则报错 | 逐文件获取，失败排除 | 拼接需要总长度 |

## 5. 各模式专属规则

### 5.1 单视频模式

| 项目 | 规则 |
|---|---|
| 导入 | 只选一个视频 |
| 选后扩展名校验 | 无（与多文件模式一致，拒绝由 ffprobe 无数据决定） |
| 跨文件兼容 | 无 |
| 分析条件 | 工具路径和源路径都不为空 |
| 分析失败 | 产生错误，阻止启动 |
| 特殊上游工具 | 使用某些上游工具时，会覆盖脚本配置 |
| 时长过滤 | 不适用 |
| 启动 | 上游请求为空则报错 |
| 脚本视频校验 | 有 |

### 5.2 队列模式

| 项目 | 规则 |
|---|---|
| 导入 | 多文件对话框；支持蓝光播放列表 |
| 导入闸门 | 导入前运行 ffprobe 可读性预检：读不出的文件逐个排除并汇总；全部读不出则拒绝导入，不覆盖已有源 |
| 空结果 | 未选择任何文件会警告 |
| 混合文件夹 | 可能报错 |
| 每文件分析 | 逐文件体检 |
| 单文件失败 | 静默排除，完成汇总一次性列出（名称 + 失败原因） |
| 全部失败 | 不能继续 |
| 过滤模式 | 文件数大于 1 时，提示首流或典型流 |
| 接受条件 | 关闭过滤则接受；否则候选必须匹配参考 |
| 实际要求 | 相同检查列表状态、相同宽度、相同归一化平均和实际帧率 |
| 不要求 | 高度不参与比较，但颜色信息参与 |
| 参考选择 | 典型模式按时长²÷帧数²投票；首流模式取第一个 |
| 结果保存 | 接受和排除结果写入队列文件 |
| 时长过滤 | 仅队列；默认 30 秒；过滤后为空警告 |
| 队列文件检查 | 文件缺失、无条目、无效内容都报错 |
| 启动前检查 | 缺失源、重复输出 |
| 脚本校验 | 强制执行脚本与视频匹配 |

### 5.3 拼接模式

| 项目 | 规则 |
|---|---|
| 导入闸门 | 无扩展名预过滤；坏文件交给兼容分析排除并汇总 |
| 最小数量 | 少于 2 个错误 |
| 同扩展名 | 所有文件必须同扩展名，忽略大小写 |
| 可变帧率 | 每文件警告，不阻断 |
| 分辨率不匹配 | 阻断；导入中止，再分析也报错 |
| 编码 / 像素格式不一致 | 警告 |
| 帧率不匹配 | 警告 |
| 无视频流或缺宽高 | 报错 |
| 单文件探测失败 | 静默排除；剩余仍 ≥2 继续分析，否则拦截并汇总失败原因 |
| 全部失败 | 不能继续 |
| 帧计数 | 累加总帧数；任一文件缺帧数则总长度不完整 |
| 参考源 | 第一个成功分析的文件 |
| 再分析 | 少于 2 个文件报错 |
| 启动数量 | 开始前再次确认至少 2 个 |
| 脚本校验 | 跳过 |
| 音频复用 | 默认重新编码为 AAC 320 kbps |

### 5.4 重分集模式

| 项目 | 规则 |
|---|---|
| 导入方式 | 文件导入支持单选与多选（可一次选中 1 个或多个视频）；也可从章节文件夹导入 |

#### 预检与阶段排除

| 阶段 | 检查 | 结果 | 说明 |
|---|---|---|---|
| 预检 | 缺少 ffprobe | 不能继续 | 做饭没锅 |
| 预检 | 没有源 | 不能继续 | 无米之炊 |
| 文件检查 | 文件不存在 | 排除 | 文件被删或移动 |
| 轻量分析 | 分析失败 | 排除 | 文件读不了 |
| 深入分析 | 分析失败 | 排除 | 视频参数读不出来 |
| 流检查 | 没有视频流 | 排除 | 没有画面流 |
| 流检查 | 宽高无效 | 排除 | 尺寸不正常 |
| 流检查 | 不是固定帧率 | 排除 | 必须是固定帧率 |
| 流检查 | 隔行 | 提示保留或排除；取消则中止导入 | 隔行会问你，说不定是伪隔行 |
| 参考比较 | 参数指纹不一致 | 排除 | 视频参数必须完全一致 |
| 帧数检查 | 帧数无效 | 排除 | 无法确定帧数 |
| 帧数检查 | 文件被改过 | 排除 | 分析后文件大小或修改时间变了 |
| 帧数检查 | 帧数估算未验证 | 提示确认；取消则中止导入 | 不精确时会问你 |

#### 参数指纹说明

| 类别 | 内容 |
|---|---|
| 编码 | 编码器、配置、级别 |
| 尺寸 | 宽、高、编码宽、编码高 |
| 像素 | 像素格式、位深 |
| 场序 | 逐行还是隔行 |
| 宽高比 | 像素宽高比 |
| 帧率 | 平均帧率、实际帧率 |
| 色彩 | 颜色范围、颜色空间、传输特性、原色、色度位置 |
| 额外数据 | 编码器额外数据的哈希 |
| 字符串处理 | 忽略大小写和空格 |

#### 帧数获取顺序

按速度排序

| 顺序 | 方法 |
|---|---|
| 1 | 使用缓存帧数 |
| 2 | 按时长估算，并抽查验证 |
| 3 | 无损重封装精确计数 |
| 4 | 完整数帧，较慢 |
| 5 | 最后用二分搜索 |

#### 计划与编辑检查

| 项目 | 规则 |
|---|---|
| 计划为空 | 报错并关闭 |
| 计划陈旧 | 文件变了，警告并关闭 |
| 文件是否被改 | 检查文件大小和修改时间 |
| 删除源 | 至少留 1 个源 |
| 删除输出 | 至少留 1 个输出 |
| 应用关闭 | 没有分析或没有输出不能保存 |
| 分割线范围 | 不能越界 |
| 最小片段 | 1 帧 |
| 启动 | 路线支持、请求有效、缺失源、重复输出、覆盖确认 |
| 脚本源 | 不要求 |
| 脚本视频校验 | 跳过 |
| 音频复用 | 默认重新编码为 AAC 320 kbps |

## 6. 主界面拖拽导入

主界面（MainUI）可以直接接收从资源管理器拖入的视频文件，导入规则与文件对话框等价。
视图层（MainUI）负责接收 OLE 拖放事件与“可以松手”的视觉反馈，规则层（MainVM）负责导入决策。

| 项目 | 规则 |
|---|---|
| 接收范围 | 主界面整体（含窗口滚动区）为拖放目标 |
| 拖入 1 个视频 | 导入到单文件模式 |
| 拖入多个视频 | 导入到队列模式（多文件模式） |
| 拖入文件夹 | 忽略文件夹；找不到可用文件时提示没有视频文件 |
| 扩展名校验 | 四种模式统一：不做扩展名预过滤；拒绝唯由 ffprobe 无数据决定（单文件报错、多文件逐文件排除）。队列模式的拖拽会先跑可读性预检，全部读不出则整批拒绝导入 |
| 目标卡片被禁用 | 提示无法导入（缺少 ffprobe，或所选上游不支持队列模式） |
| 已有视频源 | 弹确认框；确认则替换并继续导入，取消则保留原视频源 |
| 悬停反馈 | 拖入悬停时主界面显示高亮遮罩与提示文字（单文件模式 / 队列模式），表示可以松手 |
| 导入之后 | 与文件对话框导入一致，自动运行视频源检查 |
| 不支持的操作 | 只处理视频文件；脚本源仍需用文件对话框导入 |
